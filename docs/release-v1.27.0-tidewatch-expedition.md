# Frontier Survival v1.27.0 — Tidewatch Expedition

## Player-visible release

This checkpoint makes the first offshore expedition a connected journey instead of a set of unrelated survival systems:

1. Start at Cane Garden Bay with an actionable **Tidewatch Wreck** lead.
2. Gather, craft, and equip an iron pick.
3. Use a campfire to activate the expedition.
4. Follow the route to an authored offshore wreck with a torn sail, signal lantern, salvage crates, and circling seabirds.
5. Complete the existing survival-pressure return loop and receive charts/signal torches.
6. Keep named discoveries in a persistent Discovery Log shared by local co-op.

## What changed

- **Authored exploration:** Tidewatch Wreck is a deterministic, disposal-owned visual landmark connected to the actual expedition destination and save path.
- **Progression:** Discovery Log records Tidewatch Wreck, Iron Ravine, and Lantern Rootwalk discoveries with durable save compatibility.
- **Onboarding and interaction:** Fresh worlds name the next actionable step; the HUD preserves the route even before the first discovery.
- **Ecology and presentation:** Two lightweight animated seabirds, a night signal lantern, mast, sail, crates, and hull make the destination readable at normal boat distance.
- **Co-op and audio:** Co-op players see a shared crew cue; discoveries use an original Web Audio stinger rather than a generic UI tick.
- **Building bridge:** Completion pays out usable maps and signal torches, linking exploration back to harbor/home building.

## Honest scope

This release is a verified **product-quality checkpoint**, not a claim of Minecraft parity. It begins a ten-pillar program; deeper building expression, additional regional biomes/caves/destinations, long-session performance profiling, full co-op lifecycle work, and broader accessibility remain follow-up tracks.

## Release gates

Required before publication: syntax, full smoke, diff check, root/public parity, executable import cache-bust audit, local Start/runtime/visual proof, mobile/co-op checks, commit/push/tag proof, and live Pages HTML/module/browser verification.
