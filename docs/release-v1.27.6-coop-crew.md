# Frontier Survival v1.27.6 — Shared Crew White Bay

**Release type:** verified incremental checkpoint

## Player journey

1. Start Local Co-op after Tidewatch has charted White Bay.
2. When both survivors reach the overnight camp, the HUD reads **Shared crew · both at White Bay**.
3. Either player surveying notifies the whole crew and asks them to return together.

## What changed

- Added a pure crew-rendezvous helper for shared coastal camps.
- White Bay HUD and survey/claim copy distinguish solo vs both-crew presence.
- P1 and P2 still share the same White Bay handler.

## Scope remaining

This is a finished shared-route cue, not full co-op hardware proof or Minecraft-class parity. Long-session performance remains open.
